企业微信应用消息

内网服务器需要能访问 qyapi.weixin.qq.com 才能推送。员工需在「员工与权限」里填写企微 UserID；未绑定的人只会收到系统内消息。新工单会同时提醒全部在职处理人，方便抢单。不配置企微也可以正常使用全流程（系统内消息 + 页面提醒）。

企业微信通讯录同步 / 扫码免登

内网就能用：点「一键同步通讯录」把全员姓名、部门、手机号、UserID 拉进本地名录，员工扫码时姓名和部门自动联想，应用消息推送也不用手填 UserID。只需服务器能访问 qyapi.weixin.qq.com，不需要公网域名。

扫码自动带出身份（免登）：企业微信官方要求 OAuth 回调是已备案的公网可信域名，明确不支持 IP 和内网域名。填好公网地址并开启后，用企业微信扫一扫打开二维码可静默获取姓名和部门，同事一个字都不用填；相机或普通浏览器扫码仍走手动填表。

公网地址必须指向本工单系统的入口（例如 https://wo.example.com），不能填公司官网首页，否则授权回调会跳到官网、免登必然失败。若系统装在纯内网服务器，需先由 IT 打通公网链路（反向代理 / 内网穿透 / 内外网 DNS 分流）；没打通之前请保持「关闭」，并改用上面的「一键同步通讯录」。
